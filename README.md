# RISE Project Page

Static project page for **Learning Structural Illumination for Unsupervised
Low-Light Enhancement** (preprint).

## Local preview

```bash
cd 3_Pages
python3 -m http.server 4173
```

Open `http://127.0.0.1:4173/`.

## Main files

- `index.html`: page content and academic metadata
- `static/css/index.css`: layout, theme, and responsive styles
- `static/js/index.js`: carousel, scroll, and BibTeX copy behavior
- `static/js/pdf-figures.mjs`: client-side PDF.js figure rendering without viewer chrome
- `static/images/`: original paper figures used directly as PDF sources
- `static/pdfs/`: paper and supplementary material
- `static/code/rise_code.zip`: reproducibility package
